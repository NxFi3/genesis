# Original Genesis procedural assets

`low_poly.gd` creates reusable building, tree, rock, character and animal meshes at runtime. The source is an actual game asset factory used by `world_3d.gd`, not concept art. Meshes and materials are shared; repeated vegetation is instanced through MultiMesh. The geometry uses only Godot primitives and original code. No third-party art, commercial-game assets, fonts or textures were imported.
